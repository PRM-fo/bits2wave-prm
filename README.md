# SoundDrop

Send files and broadcast alerts between devices using only sound: a speaker and a microphone, with no network needed.

This repo is a single-page site (`index.html`) with a 3D scroll story (airport delay, flood and earthquake alerts) and the working SoundDrop sender and receiver apps embedded in it.

## Run it

Open `index.html` in a browser. For microphone access, serve it over HTTPS or localhost, for example `python3 -m http.server` and visit http://localhost:8000.

## Deploy with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root. The site will be live at `https://<your-username>.github.io/<repo-name>/`.
